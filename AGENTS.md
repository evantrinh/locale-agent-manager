# AGENTS

Use these rules for this repository.

## Language rule

- Write all text in ASD-STE100 Simplified Technical English.
- Use short and clear sentences.
- Do not use slang.

## Scope rule

- Keep files and structure small and clear.
- Split UI into clear files and components.
- Keep behavior simple for end users.

## License rule

- Respect the license of each reference repository.
- Do not copy code unless the license terms allow it.
- Keep license notices when reuse is allowed.

## Quality rule

- Run `npm run check`, `npm test`, and `npm run build` before finish.
- Do not commit secrets.
- Keep changes focused on the task.
